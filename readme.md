 # AI Resume Analyzer & Job Matcher

Ek Streamlit web app jo resume ko analyze karta hai aur job description se match karta hai.

## Features
- PDF aur DOCX resume upload
- Resume Score (100 me se): Skills, Experience, Education, Projects, Contact
- Job Match % job description ke hisaab se
- Matching aur Missing Skills ka chart
- ATS Checks (Summary, Education, Skills, Projects, Experience, Certifications)
- Analysis ka TXT report download

## Technologies
Python, Streamlit, pypdf2, python-docx, pandas, Altair

## Kaise chalayein
1. pip install -r requirements.txt
2. python -m streamlit run app.py
3. Browser me http://localhost:8501 kholo
